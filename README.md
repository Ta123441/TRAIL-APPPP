# TaskFlow — Professional Expo App Starter

This is a polished React Native + Expo Router starter app for Android, iOS and web.

## Recommended setup

1. Install Node.js LTS.
2. Install Expo Go on your Android/iPhone.
3. In a terminal, create a fresh Expo project:
   `npx create-expo-app@latest TaskFlow`
4. Replace the generated `app` folder with the `app` folder from this package.
5. Copy `components` and `constants` into the project root.
6. Run:
   `npx expo start`
7. Scan the QR code with Expo Go.

## Important
This source package is intentionally designed to be copied into a fresh `create-expo-app` project so Expo supplies the current compatible dependency versions.

The app is a front-end demo: tasks are stored in local component state and are not yet connected to a database or login system.
